# Proposal: Минимальная email-based OTP

## Бизнес-ценность
Добавление базовой защиты аккаунтов через email OTP без хранения состояния.

## Область применения
- Backend: API для отправки OTP и входа
- Frontend: обновленная форма входа
- In-memory cache: хранение кодов

## Критерии успеха
- Пользователи вводят username, email и password при входе
- Получают OTP на email и завершают аутентификацию
- Система работает без дополнительных настроек пользователя

## Риски
- Зависимость от email доставки

## Нагрузка
- Минимальные изменения
