# Предложение: Минимальная Email 2FA (In-Memory)

## Ценность для бизнеса
Быстрое внедрение дополнительного слоя безопасности через подтверждение по электронной почте, без сложных изменений в базе данных.

## Область действия (Scope)
- **Backend**:
  - Модификация `POST /auth/login`: поле `email` становится обязательным.
  - Хранение OTP кодов в памяти (In-Memory Map) с коротким сроком жизни.
  - Новый эндпоинт `POST /auth/2fa/verify` для проверки кода и выдачи токена.
  - "Отправка" письма через логирование (для MVP).
- **Frontend**:
  - Обновление формы входа: добавление обязательного поля Email.
  - Экран ввода OTP кода после отправки формы.

## Ограничения
- Email не сохраняется в БД и не привязывается к пользователю (вводится каждый раз при входе).
- Коды хранятся в памяти приложения (теряются при перезагрузке сервера).
- 2FA является обязательным для всех пользователей.
